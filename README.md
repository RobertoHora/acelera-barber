# Acelera Barber • Plataforma de Entrega do Kit Oficial Google

Plataforma Single Page Application (SPA) Mobile-First para ativação de presença digital e entrega de materiais do Google Meu Negócio para barbearias.

## 🚀 Recursos
- **Conexão Instagram <-> Google:** Botão de 1 toque para copiar o perfil do Instagram e link direto para o painel de gerenciamento do Google.
- **Plaquinha Oficial com QR Code:** Gerador dinâmico de display A6 em alta definição (300 DPI, 1240 x 1748 px) com logo oficial do Google e download instantâneo para impressão.
- **Checklist Interativo de Ranqueamento:** Checklist com persistência em `localStorage` para guiar o barbeiro no preenchimento de pontos cegos.
- **Roteamento Híbrido:**
  - Por ID da base de dados: `https://robertohora.github.io/acelera-barber/?id=PLACE_ID`
  - Por parâmetros de URL: `https://robertohora.github.io/acelera-barber/?nome=Barbearia+Exemplo&insta=barber_exemplo&bairro=Centro&review=https://search.google.com/...`
